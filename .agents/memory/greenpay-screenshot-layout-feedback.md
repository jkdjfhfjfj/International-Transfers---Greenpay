---
name: GreenPay screenshot layout feedback
description: How to respond when the user points out a visible gap or spacing problem in a GreenPay screenshot.
---

When the user identifies whitespace or another visible issue in a screenshot, address that rendered layout first. Do not recast the request as a startup or loading diagnosis just because the screenshot includes an error/loading message.

**Why:** The user explicitly corrected that a screenshot showing a top white band was a request to remove the visible whitespace, not investigate startup.

**How to apply:** Compare the screenshot's actual visible bounds and fix the relevant layout/background coverage before discussing unrelated runtime behavior.
