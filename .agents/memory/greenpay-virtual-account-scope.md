---
name: GreenPay virtual-account scope
description: Product scope for the currency overview and availability states.
---

GreenPay's account overview should show virtual accounts for EUR, USD, and GBP together, with each currency's own status and available balance.

**Why:** The user corrected a single-currency account display and reiterated that all three currencies belong in the overview.

**How to apply:** Keep all three currencies visible even when admin settings disable new applications for one; show its unavailable state and omit its application action.
