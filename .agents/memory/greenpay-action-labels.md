---
name: GreenPay action labels
description: The distinct send and transfer actions in wallet navigation.
---

Keep the dashboard quick action labeled “Send”. On a wallet-account page, label the account action “Transfer” and open the transfer page with that wallet selected as the source.

**Why:** The user explicitly clarified that the dashboard action remains Send, while the action on a wallet account and its destination page are Transfer.

**How to apply:** Preserve this distinction in dashboard quick actions and wallet-account navigation; carry the selected wallet ID into the transfer flow.
