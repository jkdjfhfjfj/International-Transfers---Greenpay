---
name: GreenPay card requirement copy
description: Copy rules for user-facing messages when an active virtual card is required.
---

Keep customer-facing active-card requirement messages free of references to admin roles or admin settings. Focus on the user's account state and the next action.

**Why:** The user asked not to mention admin in the card-requirement message.

**How to apply:** When editing send, exchange, or withdrawal requirement notices, describe the active-card requirement directly without pointing to system settings or who controls them.
