# GreenPay Mobile App - Capacitor Setup ✅

## Quick Start (5 minutes)

### 1. Install & Initialize
```bash
npx cap add android
npx cap sync android
```

### 2. Build Web App
```bash
npm run build --workspace=client
```

### 3. Test Locally
```bash
npx cap open android
# Android Studio opens - click Run button
```

## Native Features (Ready to Use)

### Push Notifications
```typescript
import { initPushNotifications, setupPushListeners } from 'native/plugins/push-notifications';

await initPushNotifications();
setupPushListeners();
```

### File Storage
```typescript
import { FileStorage } from 'native/plugins/file-storage';

// Save data
await FileStorage.saveCacheData('user_prefs', { theme: 'dark' });
```

```typescript

// Check availability
const available = await initBiometric();

// Authenticate
const authenticated = await authenticateBiometric('Unlock GreenPay');
```

## GitHub Actions - Auto Build to Play Store

### Setup (One-time)

1. **Generate Android Keystore**
   ```bash
   keytool -genkey -v -keystore release.keystore \
     -keyalg RSA -keysize 2048 -validity 10000 \
     -alias greenpay-key
   ```

2. **Encode to Base64**
   ```bash
   base64 -w 0 release.keystore
   ```

3. **Add GitHub Secrets**
   - `ANDROID_KEYSTORE_BASE64` - Base64 keystore
   - `ANDROID_KEYSTORE_PASSWORD` - Keystore password
   - `ANDROID_KEY_ALIAS` - greenpay-key
   - `ANDROID_KEY_PASSWORD` - Key password
   - `PLAY_STORE_SERVICE_ACCOUNT_JSON` - Google Play JSON

**See `.github/GITHUB_ACTIONS_GUIDE.md` for detailed instructions**

### How It Works

**Automatic** (on every push to `main`):
- Build web app
- Sync to Android
- Build release bundle
- Upload to Play Store **internal testing** track
- Status: Draft (ready for review)

**Manual** (workflow_dispatch):
- Internal testing (draft)
- Alpha testing (draft)
- Beta testing (draft)
- Production release (immediate)

## Troubleshooting

### Capacitor not found
```bash
npm install @capacitor/core @capacitor/cli --legacy-peer-deps
npx cap --version
```

### Android sync fails
```bash
rm -rf android/
npx cap add android
npx cap sync android
```

### Build fails locally
```bash
cd android
./gradlew clean
./gradlew assembleDebug
```

### Web app not loading in app
- Verify `npm run build --workspace=client` succeeded
- Check `client/dist/` exists
- Verify `webDir: 'client/dist'` in `capacitor.config.ts`

## Version Management

Always increment `versionCode` in `android/app/build.gradle` before building:

```gradle
defaultConfig {
    versionCode = 1  // Must be unique per upload
    versionName = "1.0.0" // User-facing version
}
```
